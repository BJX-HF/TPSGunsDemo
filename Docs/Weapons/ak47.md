第二格的原 Rifle_7 已改名为 ak47。出生顺序为 Rifle、ak47、Pistol。

旧 DA 的数值保留，配置索引已指向 `ID_ak47`。物品名称、装备名称、拾取名称、源代码预设、Golden 文件和当前调参文档同步改名。历史验收归档保留原来的事实记录；迁移脚本中的旧名只用于定位迁移输入。

模型使用 Tabasco 发布的 CC0 AK-47（低多边形、材质分区，无原始纹理贴图），详见 `SourceArt/Weapons/ak47/SOURCE.md`。尺寸约 94 cm，右手握点对齐现有武器原点。保留原步枪骨架参考姿势和动画：枪身→Grip、弹匣→Magazine、枪栓→Bolt、扳机→Trigger，全部使用单骨骼刚性权重。

`B_ak47` 是独立枪身蓝图，第一格继续使用 `B_Rifle` 和 `SK_Rifle`。Muzzle / ShellEject / ShellEject_0 是新网格上的覆盖插槽，原共享骨架的插槽没有修改。Muzzle 位于 Grip 空间 `(64.2, 0, 9.9543)` cm。

## 重新生成

在项目根目录运行：

1. Blender 4.2：`blender -b --python Docs/Weapons/Tools/prepare_ak47.py`。
2. UE Python commandlet 执行 `Docs/Weapons/Tools/import_ak47.py`，随后执行 `bind_ak47.py`。需启用 `PythonScriptPlugin,EditorScriptingUtilities`。
3. UE commandlet：`-run=LyraWeaponConfig -ak47sockets`。
4. 执行 `validate_ak47.py`，并运行 `Lyra.Recoil.WeaponConfig.Ak47Rig` 自动化测试。

`rename_ak47.py` 是一次性、可重入的旧资产改名迁移工具；不重新生成或重置 DA 参数。

角色姿态渲染：`-run=LyraAk47Preview -AllowCommandletRendering -unattended -nosplash -nosound`，不要传 `-nullrhi`。输出位于 `Saved/AK47Work/engine_pose_*.png`。
