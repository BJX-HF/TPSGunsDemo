## 1. 一句话

把**散布的数值配置从武器实例蓝图搬进后坐力配置资产**，模型从「heat → 三曲线」的间接模型

**默认关闭**（`bEnableProfileSpread = false`）⇒ 不勾开关时行为逐位等于改造前。

### 2.2 单位口径（写死，后续不许改）

- **全锥角（直径角），度**。唯一半角换算点：`LyraGameplayAbility_RangedWeapon.cpp` 的 `ActualSpreadAngle * 0.5f`。
- `Base` 是**地板**不是起点：稳态下 `CurrentSpreadAngle == Base`。
- 姿态（蹲 / 空中）**瞬时切换**；只有"站定 ↔ 移动"走 `FInterpTo` 连续过渡。
- **`Lyra.Recoil.Enable 0` 不会关掉散布** —— 两个系统刻意解耦，便于"只调散布"的 A/B 对比。

### 2.3 新增的 7 个用例

| 用例 | 断言了什么 |
| --- | --- |
| `Lyra.Recoil.Spread.DisabledIsNoOp` | 新建资产默认 `bEnableProfileSpread == false`；关闭时 `ApplySpreadShot` / `AdvanceSpread` **逐位不动**状态；`ShotHistory.SpreadAngle` 恒为 0 |
| `Lyra.Recoil.Spread.AccumulateAndClamp` | 手算序列 `1.0 → 1.5 → 2.0 → 2.5 → 3.0 → 3.0`（封顶）；`Reset` 后从**站立基础角**起步而不是 0 |
| `Lyra.Recoil.Spread.Recover` | 停火延迟边界（`<=` 时不回落）；越过后按 `2.0 度/秒` 回落（3.0 → 2.5）；钳在基础角 1.0 |
| `Lyra.Recoil.Spread.PoseSwitch` | 蹲下立刻钳到蹲伏上限 1.0；**起跳把锥角抬到新基础角 2.5**（不是回落）；空中 `recover=0` 不回落；落地回到 1.0 |
| `Lyra.Recoil.Spread.PlayerMultipliers` | 瞄准 `Lerp(1, 0.5, α)`；移动 ramp 四个边界；**带宽为 0 的退化区间不产生 NaN**；负倍率被夹成 0 |
| `Lyra.Recoil.Spread.ProfileParams` | 各姿态参数解析正确；`Max < Base` 被 `ValidateProfile` 报错且**错误消息点名到字段**；出口兜底把 `Max` 抬到 `>= Base`；负值夹成 0 |
| `Lyra.Recoil.Spread.ToggleBackIsClean` | 累加过之后关闭开关再 `Reset`，三个角度字段（Current / Base / Max）**全部归零**，且后续开火不再累加 |

> - **A（推荐，安全）**：编辑器里打开 `DA_Recoil_Rifle_S`，勾上 `bEnableProfileSpread`，

### 步骤 4：玩家侧倍率

| 操作 | 预期 |

| 对不上 | 先看 `effective` 对不对；`effective` 对而准星不对 ⇒ 问题在 HUD，不在散布系统 |

### 步骤 6：A/B 归因（确认两套系统真的解耦）

| 操作 | 预期 |
| --- | --- |

## 6. 待确认项

### 1) 首版散布数值未经实机验证（**最主要的待确认项**）

我按武器类型的常规量级填的（步枪第 7 发到顶 / 手枪回落 3.5 度每秒 / 霰弹基础 3.5°），
**没有做过 PIE 手感验证**。数字表在 `12_SpreadInProfile.md` §8。

**请确认**：先在 PIE 里打几轮定稿，还是先按首版值走、后续再调？

> 更稳的路径（我推荐）：**先别勾开关**，用 `Lyra.Recoil.SpreadDebug 1` 观察旧模型的锥角范围，
> 照实测值把新参数填一遍，再打开开关对比。

### 2) 是否要重生成 5 份资产

`gen-recoil-assets.ps1 -Force` 会**同时覆盖后坐力数值**（Rifle_S / Rifle_7 是手调过的，会丢）。

**请确认**：走 A（手工勾开关）还是 B（脚本重建）？

### 3) 两个调参 CVar 要不要补

目前**没有** `Lyra.Recoil.Spread 0/1`（散布总开关）与 `Lyra.Recoil.SpreadScale <f>`（散布倍率）。
A/B 对比只能改资产。补的成本很低（同一个 `ULyraRecoilDebug` 里加两行）。

**请确认**：补还是不补？

### 4) 参数单位用"全锥角"还是"半角"

我选了**全锥角**（与 Lyra 原生 `CurrentSpreadAngle` 一致，GA 里有现成的 `× 0.5`）。
若你要"我要 2° 的离散"这种半角直觉，需要改 `GetCalculatedSpreadAngle()` 的语义 + 准星，属破坏性改动。

**请确认**：维持全锥角？

### 5) 两个已知缺口是否现在补

| 缺口 | 我的建议 | 理由 |
| --- | --- | --- |
| **散布曲线**（DLC36 的 `bUseShootScatterCurve` + 两条曲线） | **先不做** | 会削弱 CSV 的"可手算复核"性质；且当前线性累加够用 |
| **姿态切换过渡**（蹲/跳瞬切会让锥角跳一下） | **先不做** | 会破坏"每发按当下姿态取值"的口径，而 P4 的比值判据依赖它。**建议先实机确认观感能否接受** |

**请确认**：是否同意先不做？

### 6) 旧 heat 字段要不要留着

15 个旧字段全部保留在 `Spread (deprecated)` 分类（含 `bAllowFirstShotAccuracy`），
作为回退路径。删掉会让既有武器蓝图的序列化数据静默丢失，也会失去"零回归"的对照物。

**请确认**：留着（我建议）还是彻底删掉？
