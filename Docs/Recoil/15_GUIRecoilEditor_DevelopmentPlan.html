05 · 参数映射与双向转换

5.1 坐标与数据域

定义数组长度 N = PatternPoints.Num()，固定区间长度 L = PatternLength，基础强度 H = RecoilPerShot_Horizontal、V = RecoilPerShot_Vertical，曲线倍率 c[i] = Profile.GetVerticalKickCurveScale(i)。画布配置基准固定为姿态倍率=1、全局倍率=1；预览倍率不参与资产反算。

// 固定段：0 ≤ i < L；P[-1] = (0, 0)，所有角度单位为度
ΔYaw[i]   = H × PatternPoints[i].X
ΔPitch[i] = V × PatternPoints[i].Y × c[i]
P[i]      = P[i-1] + (ΔYaw[i], ΔPitch[i])

// 编辑累计点后反算（分母可逆且结果在合法范围时）
Δ[i] = P[i] - P[i-1]
PatternPoints[i].X = Δ[i].X / H
PatternPoints[i].Y = Δ[i].Y / (V × c[i])

// 实际每发计算额外乘 M，不反写入 Pattern
M = max(0, PoseMultiplier) × max(0, GlobalScale)
VerticalKick   = V × GetPatternPoint(i).Y × c[i] × M
HorizontalKick = H × ComputePatternHorizontal(Profile, i, Seed) × M

正向装载必须调用现有曲线求值接口，不手写一套“空曲线=0”的替代实现。当前无曲线数据返回 1；有数据时直接 Eval，包含插值、外推与外部引用。计算使用双精度中间值，提交时转为现有 float 字段并再做正向重建检查。

5.2 相邻点影响必须可见

累计点 P[k] 移动 d、其余点保持原位时，Δ[k] += d，若下一固定点存在，则 Δ[k+1] -= d。因此一次拖动可能使下一发 Y 变负或超限。必须校验整个受影响段，不能只校验选中点。固定段最后一点后的随机水平线由运行时重新计算；后续数组 Y 默认保持原参数，不用随机坐标反算。

多选拖动将所有选中累计点同时平移；连续选择内部的增量通常不变，边界发发生变化；非连续选择需计算每个边界。首版不提供容易混淆的隐式“带动所有后续点”模式：用户要改变一发且平移后续累计位置时，可直接编辑该发的归一化值或逐发角度。

5.3 尾段与空数组

  • L < N 合法：数组尾部 X 当前不参与水平计算，但仍必须原样保留；尾部 Y 继续参与垂直计算。
  • L=0 时无双轴固定点，随机预览从第一发开始；逐发表格仍可编辑数组 Y 和保留的 X。
  • N=0 时显示“空数组，运行时使用 GetPatternPoint 的退化值”，不自动插入默认点；预览继续调用实际接口。现有退化点为纯垂直配置，新增必须是显式命令。
  • 预览发数可以大于 N；自动生成的重复/随机点不能被删除或选为可写节点。若要编辑该发，先明确扩展数组或固定区间，展示由此产生的行为变化。

06 · 可表达范围与错误处理

默认策略是拒绝不可表达的提交，保留原资产并解释原因。拖动过程中显示红色候选位置和错误；松手校验失败则恢复开始位置，允许用户在诊断面板查看候选数值并显式选择调整方案。任何调整都必须先给出具体变化预览。

条件处理合同
H>0、V×c[i] 可逆按公式计算并验证 X/Y 范围。c[i]>0 时 ΔPitch∈[0,Vc]；c[i]<0 时 ΔPitch∈[Vc,0]。负曲线并非被运行时自动钳成零：界面显示“本发为向下 Kick”，仍按带符号分母反算，禁止擅自取绝对值或改曲线。
H=0 或 V×c[i]=0对应角度轴不可逆。原角度为零且本轴未改时保留原始 X/Y，不能把隐藏值写成 0；请求非零增量则拒绝。可通过原始表格显式改隐藏值，但提示当前角度不变。
极小分母建议以 |分母|≤1e−8° 作为反算锁定阈值，作为编辑器数值安全常量测试；不改变运行时求值。装载仍展示精确结果，未改轴原样保留；用户改强度或曲线后再解除锁定，禁止以 epsilon 代分母。
X/Y 超界或候选 Pitch 方向不支持报具体发序号、候选归一化值及允许区间。主路径回退；可显式调用“将候选投影到合法范围”，但须展示逐发误差与最终累计误差后应用，并标注这是有损调整。
NaN、Inf、溢出检查原始字段、曲线采样、坐标变换、除法与 float 转换结果；阻止对应编辑/预览/本工具保存，定位问题。禁止把非有限数传入 Slate 绘制；保留资产以便修复，不能静默清零。
负基础强度 / 既有非法数据不通过打开编辑器自动修复；显示原值与校验错误，允许明确修复。GUI 自身的保存校验需覆盖现有 ValidateProfile 和编辑器附加的有限数检查。
曲线负值、跨零、外推按实际 GetVerticalKickCurveScale(i) 采样，整数发序号各自判断。正负交替时每发范围不同；不能以单一全局 Y 限制代替。预览范围外曲线不承诺已穷举验证，保留引用与外推语义。
浮点边界建议归一化容差 1e−6、角度重建容差 1e−5°+1e−6×|目标角度|。仅允许容差内舍入归并到边界，并在诊断记录最大误差；超过容差绝不钳制后声称无损。具体阈值在 P1 测试锁定。

显式“调整基础强度以容纳候选”

作为首版高级命令提供，不能拖动时自动触发。前提是强度非负、曲线有限且方向匹配；零曲线要求该发目标垂直增量也为零。建议候选强度：H' = max(H, max|ΔYaw|)；V' = max(V, max(ΔPitch/c[i]))，只纳入可逆且符号相容的目标发。随后基于候选强度重新归一化，整组字段一次事务提交。

  • 对所有已存在且可生效的有限数组发，保留未主动编辑发的目标逐发角度；固定段 X 和全数组 Y 一并计算候选，而不是只改选中点。按新分母反算：新分母仍不可逆且目标为零时保留原值；原分母为零而新分母可逆时，原先隐藏的值可能需要改为零才能保留零角度，必须在差异面板列出并随高级命令明确应用，不能声称这些原始值也被保留。
  • 尾段未生效 X 原样保留。H 改变会改变随机尾段实际幅度；V 改变及重新归一化可能影响数组外沿用值和曲线外推处结果，尤其最后一点采样为零时。预览必须显示这些差异，不得承诺“全运行时无损”。
  • 对 N 之外的尾段做指定发数、多个固定种子的前后比较；对无法保证的无限尾段明确标注。用户确认具体差异后才应用高级命令。
  • 不自动调整 HorizontalRandomRange、姿态、上限，不重置 VerticalKickCurve 为 1。若当前数据无法满足这些条件，禁用该命令并建议手工修改参数。

基础强度或曲线在详情面板直接改变时，默认保持 Pattern 原值、重建累计点，意味着有意改变手感；与上述“保持目标角度而重新归一化”的高级命令在名称、说明和事务标题上严格区分。

07 · 增删、重排与 PatternLength

结构操作默认保留既有节点的归一化 X/Y，按新序号重新采样曲线并重建累计点。不得为了固定旧累计坐标而偷偷改相邻节点。结构预览同时展示顺序、L/N、逐发角度和曲线采样的前后差异。

操作明确规则
打开、重载、缩放、选中L 与 N 均不改变。现有 Profile 在 PostLoad/PostEditChangeProperty 中有 SanitizePatternLength，会将 L 限于 [0,N]；编辑器应读取最终值，不能再额外令 L=N。
在索引 k 插入 m 个节点0≤k≤N；若 k<L，则 L'=L+m；若 k>L，则 L'=L；若 k=L，默认归入尾段、L 不变，提供明确的“插入固定段”选项令 L'=L+m。N'=N+m。
新增值默认归一化 (0,0)，或显式选择复制前发。画布“在此插入”仅用于固定段，按目标点与前一点算出新发参数，后续旧节点保留其归一化值并重算位置；提交前展示曲线索引变化。
删除选择集 D一次性按操作前索引计算：N'=N−|D|，L'=L−|{i∈D且i<L}|。剩余节点的归一化值保留。删光后 N=L=0，不自动补默认点。
重排N 和 L 的数值不变，固定段仍为新顺序的前 L 个节点。跨边界交换使部分 X 开始/停止生效，且 Y 曲线采样序号变化；必须预览并明确应用。
改变 L显式设置 0…N，数组长度和原始点不变。增大 L 将原尾段 X 激活，减小 L 开始随机游走；预览从边界起失效并重算。
数组直接增删详情面板的 PatternPoints 数组结构按钮由定制界面路由至同一命令服务，避免绕开规则。来自外部工具的更改接受其最终资产值，刷新并提示差异，不擅自套用本工具操作规则。
自动排序默认关闭、不随拖动触发。若实现一次性排序，按累计 Pitch、再原顺序稳定排序；按上述重排规则保存 X/Y，展示重新采样结果，不把排序前累计坐标当保存目标。

复制粘贴格式与保护

使用带标识和版本号的 JSON 文本（例如 LyraRecoilClipboard/v1），记录序号顺序、原始 X/Y、可选源逐发角度、源 H/V 与采样倍率，仅作为剪贴板载荷，不是新的配置资产。默认“粘贴归一化参数”，在当前插入位置按上述规则执行。

“按角度粘贴”在目标资产的强度和曲线下重新反算，并明确不复制源曲线引用。非连续选择按原发序号排序，复制原始逐发增量，不把所选累计点重新做差。校验版本、节点数量、数值类型、有限性及输入大小；未知版本或损坏数据整体拒绝。首版可限制单次粘贴为 4096 点、文本 1 MiB，作为编辑器保护值而非运行时资产上限。粘贴失败零写入，成功一次 Undo。

08 · 事务、保存与外部曲线

8.1 编辑提交与磁盘保存分开

采用 UE 常规资产编辑方式：每个合法操作完成后立即提交到内存中的原 Profile并标脏；Ctrl+S 才持久化到 .uasset。临时累计点不是等待另一次“应用”的第二份配置；只有正在进行的拖动草稿可以短暂与资产不同。

  1. 开始操作时记录受影响字段、节点 ID、资产修订号与曲线依赖修订号。拖动只更新临时模型，不逐帧调用 Modify 或改真实资产。
  2. 结束时先在临时候选 Profile 上做转换、字段范围检查、ValidateProfile 与有限数检查，再正向重建验证；校验失败不进入事务。
  3. 合法且确有变化时建立一个 FScopedTransaction，对 Profile 及参与 Undo 的临时 UObject 调用 Modify()，执行正确的属性前后通知，提交最小字段差异。数组元素编辑使用合适的链式属性通知；结构命令在整组 N/L 写完后发一次完整通知，避免中途 Sanitize 改坏边界。
  4. 通过项目采用的属性通知/包 Dirty 路径标脏，读取 PostEditChangeProperty 后的最终状态，并刷新工作模型、详情与预览。自定义通知和 Property Handle 通知不得重复发送或嵌套事务。
  5. 比较为无变化时不建事务、不标脏。Esc、鼠标捕获丢失、资产失效或修订冲突时直接丢弃草稿，不需要一次“反向写回”。

详情面板普通字段沿用 PropertyEditor 的事务；Pattern 与结构字段通过同一编辑命令校验。Undo/Redo 必须同时还原 Profile 和必要的临时 ID 映射，随后从资产重建派生坐标。保存本身不清空撤销栈，撤销到已保存内容也不手工篡改引擎 Dirty 判断。

8.2 保存、另存与关闭

  • 保存：先结束当前有效输入或取消拖动，再校验真实 Profile；只保存目标资产包。复用引擎源控/只读/保存错误处理。失败保留 Dirty 和内存修改，不显示“保存成功”。本工具的校验不是对任意外部脚本保存行为的全局拦截。
  • 另存：以当前已提交内存值复制为新的 ULyraRecoilProfile，重新分配包路径/资产名，成功保存后打开新编辑器；保留原资产当前 Dirty 状态与引用。不会自动把武器切换到新资产，也不覆盖同名资产而无标准确认。
  • 关闭：采用 UE 标准的保存/不保存/取消关闭语义；不额外自动提交非法草稿。明确“不保存到磁盘”与“把共享内存对象恢复到磁盘版本”不是同一件事。若提供“从磁盘重载”，需显式提示它会影响同一资产的其他编辑入口。
  • 共享资产：打开时显示路径及可选引用查看入口；修改同一个 Profile 会影响所有引用它的武器，想单独调一把枪应先另存再由用户显式改武器引用。
  • 原样保存：未改过的隐藏字段、尾部 X、曲线键及外部引用必须保留。无操作打开/关闭不触碰包；保存重载测试以序列化属性等价为准，不把 .uasset 二进制哈希相同作为引擎重新保存的唯一判据。

8.3 外部曲线的所有权

FRuntimeFloatCurve 可能引用共享 UCurveFloat。GUI 默认只读展示外部曲线内容，显示资产路径与“共享引用”标志；内联曲线可在 Profile 事务中编辑。所有曲线类别均采用同一规则，而不只保护 VerticalKickCurve。

用户动作必须采取的路径
更换曲线引用只修改 Profile 引用，不修改被引用对象；重新求值、校验与预览。
为此 Profile 独立调曲线提供“复制为内联曲线”：复制当前有效 RichCurve 的键、切线、插值、外推与默认值后清除外部引用，一次 Profile 事务，可撤销；不只复制采样点。
保留资产形式但不共享明确“复制为新曲线资产”，通过引擎创建/保存流程生成新资产后换引用。资产创建与文件删除不假装可由普通属性 Undo 全部撤回；取消或失败时不换引用，说明已创建但未引用资产的状态。
编辑原共享曲线只能通过明确的“打开共享曲线资产”动作；提示其他引用者也受影响。该曲线有独立的事务、Dirty 与保存流程，本工具 Ctrl+S 不顺带保存所有曲线。
另存 Profile默认保留外部曲线引用，不宣称获得深度独立副本；另存结果中继续显示共享标记。

09 · 对象生命周期、选择 ID 与同步

建议由资产工具包拥有一个 ULyraRecoilEditorSession（Transient、RF_Transactional）和独立预览对象。Session 持有可事务化的节点身份映射；累计坐标、校验结果、视图状态为可重建缓存。不得把 Session 存入 Profile 的运行时 UPROPERTY。

  • GC：工具包采用 FGCObject::AddReferencedObjects 或项目兼容的强引用机制保护 Profile、Session 和临时预览快照；TSharedPtr 本身不能保护 UObject。Slate 回调使用弱工具包/弱 UObject，执行前检查有效性。
  • 稳定 ID：节点用会话内 FGuid 标识，数组索引只表示当前发序号。拖动、重排与本工具 Undo/Redo 保持身份；复制生成新 ID；删除移除 ID；同坐标点仍可分别选中。ID 不进入运行时资产。
  • 外部结构修改：外部工具可能无法提供节点身份。可证明只改数值且数组结构没变时保留索引映射；不能证明时重建 ID、清空选择并提示，不能凭相同坐标猜身份。重载/对象替换后同样重建。
  • 属性同步：监听目标 Profile 与当前曲线依赖的属性改变，以及 Undo/Redo、资产重载/替换事件。按当前引擎 API 注册并保存 DelegateHandle，关闭或模块卸载时逐个解除。
  • 防重入：自提交时使用作用域同步保护，合并通知；同一资产更新只导致一次重建。外部修改到来时先终止本地拖动，再接收最终资产值，提示“资产已在其他入口更新”，不覆盖外部新值。
  • 修订校验：每次有效属性或曲线依赖变化递增修订；手势记录开始修订。提交前不匹配则拒绝草稿。修改曲线引用时先解绑旧依赖，再绑定新依赖。
  • 多窗口：同一资产优先复用已有工具包；若出现多个窗口，均从对象通知同步，不允许长期持有互相覆盖的可写副本。分别打开不同资产时状态与命令列表隔离。
  • 拖动取消：Esc、失焦导致捕获丢失、关闭、Undo、资产重载均取消当前手势并恢复原选择/视图适当状态；鼠标松开后不再补一次提交。
  • 预览清理：关闭工具包时取消 ActiveTimer/Ticker、解除属性监听并释放快照；禁止后台回调访问已销毁 Slate。Live Coding/模块重载后命令与资产动作不得重复注册。

预览首版在编辑器主线程以有限预算增量计算。若后续改为后台计算，必须先把 UObject 及曲线读数复制为安全快照，并证明现有运行时调用线程安全；不要直接把 UObject 访问放进任务线程。此扩展不是首版依赖。

10 · 使用现有运行时的数值预览

10.1 预览边界和输出通道

创建原 Profile 的隔离临时副本作为预览输入，深复制有效外部曲线到临时内联曲线，以固定本次回放快照；只在副本上覆盖固定种子等预览选项。预览从不写真实资产、不借用 PIE 正在运行的武器状态、不改变全局 CVar。

曲线 / 数据取得方式必须说明的含义
理论累计 Kick累加现有 ComputeShotKick 的输出，配置图使用倍率 1。未经过相机上限、回弹和回正，不能标成实际相机轨迹。
相机偏移GetCameraPitchOffset / GetCameraYawOffset；可选 Roll 通道。由运行时 Advance / ApplyShot 得到，包含插值阶段与饱和。
ControlRotation 与可见角度独立输入脚本维护 ControlRotation；角度示意为 ControlRotation + CameraOffset。不能把显示合成结果再反馈为玩家输入。完整相机边界、其他 Modifier、FOV 与枪模最终效果以 PIE 验证为准。
每发方向偏移GetShotDirectionOffset / ComputeShotKickGated，取本发索引和当时倍率、种子。逐发方向参数，不累加成弹着点；首版不做伪“真实弹着散点图”。
状态与诊断ShotIndex、ShotHistory、State、InterpStage、RecoveryPeak/Cover、上限与回正目标。显示真实状态机值；诊断通道只读，不反向写参数。

10.2 时序合同

  1. 快照完成后调用 Reset(ProfileSnapshot)，设置全局倍率、姿态/瞄准与初始玩家瞄准。预览覆盖种子使用副本的 Fixed 模式和指定值；由于新轮次可能 ResolveSeed，仅设置一次 ActiveSeed 不可靠。
  2. 射速为预览输入 RPM>0，间隔 60/RPM，t=0 第一发；建议默认 600 RPM、20 发、1/60 s 外层步长。若从选定武器读取射速，显示来源，不能假定 Profile 自身存有射速。
  3. 按确定的时间事件推进：到达发射/输入关键时刻前先推进上一段时间；每次 Advance 前采样当前玩家瞄准，再调用 Advance；开火前再次 SamplePlayerAim 并刷新倍率。
  4. 开火事件读取本发方向偏移并调用 ApplyShot；本发索引、状态重置和种子时机须与 ULyraRangedWeaponInstance 及实际发射调用链对照，以同输入轨迹测试锁定。不得在预览额外递增 ShotIndex 或自行判断进入回正。
  5. 同时间戳按“输入/姿态更新 → 开火前采样 → 发射事件 → 记录”确定顺序；跨发射边界拆分外层步长，避免射速受编辑器帧率影响。保留现有 Advance 内部子步与长帧保护，不重写其阶段算法。
  6. 停火后继续 Advance 至指定尾时长并观察 Idle；不得看到 Idle 就清零偏移或重置输入。第二轮连发和回正中重开火沿用同一个状态实例，只在点击“重置回放”时 Reset。
  7. 拖时间轴向后跳时从 t=0 用同一快照重放或用验证过的完整状态检查点；不能用插值几个输出值代替重新推进状态机。播放速度只影响播放墙钟速度，不改变模拟时间步。

基准确定性回放与“长帧场景”分开：标准回放精确命中事件；长帧测试显式把大 DeltaSeconds 传给现有 Advance，以覆盖其真实收尾分支。不能把长帧全部切碎后声称覆盖了长帧保护。

10.3 必备场景

  • InstantWrite 与 Interpolated 分别进行单发、持续连发、停火回正；显示 Lift / Rebound / Settle / Drop。RecoveryDelay 的现有复用语义保持不变。
  • 固定段边界前后、N 之后尾段；同种子重复播放逐样本一致，不同种子只改变受随机逻辑影响的结果；预览覆盖种子不改变资产设置。
  • 站立、蹲伏、空中，瞄准 Alpha=0/0.5/1；全局倍率=0/1/其他正值。配置画布位置不随这些预览选项变化。
  • 起枪 0°/30°、实际受限上跳 10°、下压 0°/4°/10°/11°；采用既有测试夹具与输入时序，在两模式中核对最终可见角度。
  • 连续两轮、Drop 中重开火、接近 Pitch/Yaw 上限、回弹饱和和长帧；部分压枪与超压都要覆盖。
  • 固定步长 30/60/120 Hz 的结果与现有运行时在相同输入步长下逐样本比较；不要求不同步长下所有中间样本位级一致。

输入脚本用带时间戳的玩家瞄准角/增量表达，在每帧及开火前送入 SamplePlayerAim；禁止直接写 RecoveryCover、RecoveryTarget 或 AimCompensation 来伪造通过结果。若加入散布数值预览，复用现有 ApplySpreadShot/AdvanceSpread 及武器调用顺序；若加入 WeaponVisual 数值通道，复用现有独立状态，完整动画仍需 PIE。

任何资产/曲线/预览输入改变都使缓存失效并从头计算，避免新旧参数混合。建议首版预览上限 4096 发、120 秒；大图节点裁剪绘制、重复样本缓存，超限给出原因。阈值只限制工具工作量，不更改运行时资产有效范围。
