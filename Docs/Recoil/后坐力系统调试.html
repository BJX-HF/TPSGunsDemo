后坐力系统调试

可调参数与 Debug 速查 · TPSGunsDemo
后坐力单发与回正Roll散布弹匣、备弹与射速Debug 命令读数与排错
角度单位均为度。后坐力参数位于当前武器的 DA_Recoil_* 资产；DA_Recoil_Rifle_S 与 DA_Recoil_Rifle_7 目前都使用 Interpolated 单发模式。表中的“默认”是字段默认值，具体枪械请以资产面板中的值为准。

1 · 后坐力与轨迹参数

Recoil | Base / Curves / Pattern

参数含义
RecoilPerShot_Vertical每发基础垂直力度；与轨迹点 Y、垂直力度曲线及姿态倍率共同决定抬枪量。
RecoilPerShot_Horizontal每发基础水平力度；与轨迹点 X 及姿态倍率共同决定左右摆幅。
VerticalKickCurve按发序号调整垂直力度。横轴为从 0 开始的发序号，纵轴为倍率；不改变水平力度。
PatternPoints固定轨迹点。X 控制水平走向，Y 控制垂直走向；调整点位可改变 S 形、7 字形等图案。
PatternLength固定轨迹覆盖的发数，不可超过轨迹点数量；之后进入随机区间。
HorizontalRandomRange固定轨迹结束后的水平随机游走范围，单位为归一化轨迹量。越大，后续左右偏移越明显。
RandomSeedMode / FixedRandomSeed选择随机种子的取得方式；固定种子用于复现随机段。固定种子字段仅在固定模式下生效。

Recoil | Multipliers / Clamp

参数含义
PoseMultiplier_Standing站立时的后坐力倍率。
PoseMultiplier_Crouching蹲伏时的后坐力倍率。
PoseMultiplier_JumpingOrFalling跳跃或下落时的后坐力倍率。
PoseMultiplier_Aiming完全瞄准时的倍率；瞄准混合期间从 1 平滑过渡到本值，并与姿态倍率相乘。
MaxVerticalKick垂直累加偏移的限制值。压枪时上限会随压枪量作补偿，不能把它简单理解成屏幕净抬升的固定上限。
MaxHorizontalKick水平累加偏移上限。

2 · 单发与回正参数

分类 / 参数含义
SingleShotModeInstantWrite：开火时直接写入偏移；Interpolated：依次经历 Lift 上抬、Rebound 回弹、Settle 停留、Drop 回正。两把示例步枪目前均为后者。
LiftDurationLift 上抬时长，秒；增大后抬枪过程更慢。仅插值模式生效。
ReboundDurationRebound 回弹时长，秒；仅插值模式生效。
ReboundRatio回弹后保留的本发幅度比例，范围 0～1；越小，本发回弹越深。连发时按“进入本发时的基底 + 本发幅度”计算，不会把此前累计偏移逐发缩小。
LiftCurve / ReboundCurve分别控制上抬和回弹段的进度形状；横轴为该段归一化时间，纵轴为完成比例。
RecoveryDelay进入正式回正前的停留时间，秒；插值模式下也是 Settle 段时长。
RecoveryTime正式回正时长，秒；插值模式下对应 Drop 段。
RecoveryCurve回正进度曲线；横轴为归一化时间，纵轴为回正完成比例。
bCompensationAwareRecovery压枪抵扣总开关，默认开。开启时垂直回正目标按本轮累计压枪量计算；关闭时偏移回到 0。
bCompensationAwareRecoveryYaw水平轴压枪抵扣开关，默认关。开启时 Yaw 也采用抵扣规则；关闭时水平偏移回到 0，玩家水平转向仍保留。
现行回正读法：抵扣开启时，回正终点最多保留到本轮峰值，即 min(累计压枪量 P, 本轮峰值 K)。P≤K 时画面回到开枪前的角度；P>K 时不反向抬镜头，画面保留超压角度 K−P。压枪量在进入回正时冻结；插值模式的 Drop 已是正式回正，Drop 中再次开火会从当前可见偏移开始新一轮。

3 · Roll 震屏参数

Roll 是独立的镜头横滚震动，不计入 Pitch/Yaw 累加与回正。参数位于 Recoil | RollShake。

参数含义
bEnableRollShake当前资产的 Roll 开关；关闭后不影响 Pitch/Yaw。
RollShake_Amplitude基础振幅，度；增加后横滚更明显。
RollShake_Duration单次震动持续时间，秒。
RollShake_Period震动周期，秒；越小振动越快。
RollShake_PhaseJitter每次震动的随机相位范围，弧度；0 表示没有相位扰动。
RollShake_AmplitudeCurve振幅衰减曲线；横轴为归一化时间，纵轴为保留比例。
RollShake_EndAmplitudeRatio末段保留的振幅比例；0 表示完全衰减至 0。
RollShake_AmplitudePerShot达到起始发数后，每发增加的振幅，度。
RollShake_RampStartShot连发振幅开始增长的发序号，从 0 计。
RollShake_MaxAmplitudeBonus连发附加振幅的上限，度。
RollShake_SegmentScaleCurve按发序号调整整次震动振幅的倍率。
RollShake_PeriodScaleCurve按发序号调整周期的倍率；小于 1 时震动更快。

4 · 散布参数

散布与后坐力可分别调试。只有打开资产上的 bEnableProfileSpread，下列资产散布字段才生效；关闭时使用 Lyra 原有的 heat 散布配置。资产散布角为全锥角，弹丸采样使用半角。
参数含义
bEnableProfileSpread资产散布模式开关；默认关。开后使用本资产的姿态角度参数。
SpreadAngle_Standing
SpreadAngle_Crouching
SpreadAngle_JumpingOrFalling		各姿态的基础散布全锥角，度。姿态切换立即选择对应参数。
MaxSpreadAngle_Standing
MaxSpreadAngle_Crouching
MaxSpreadAngle_JumpingOrFalling		各姿态的散布上限，度；不得小于对应基础角。
SpreadAddPerShot_Standing
SpreadAddPerShot_Crouching
SpreadAddPerShot_JumpingOrFalling		各姿态每开一发增加的散布角，度，增长到对应上限为止。
SpreadRecoverRate_Standing
SpreadRecoverRate_Crouching
SpreadRecoverRate_JumpingOrFalling		各姿态停火后的回落速率，度/秒；0 表示当前姿态下不回落。
SpreadMultiplier_Aiming完全瞄准时的散布倍率，随瞄准混合权重从 1 过渡到本值。
SpreadMultiplier_StandingStill站定时的散布倍率；速度升高后目标倍率过渡到 1。
SpreadStandingStillSpeedThreshold“站定”的速度阈值，cm/s。
SpreadStandingStillToMovingRange从站定阈值到移动倍率 1 的过渡带宽，cm/s；0 表示阶跃变化。
SpreadTransitionRate_StandingStill站定与移动倍率的插值速率；越大越快，0 为立即切换。
SpreadRecoveryDelay停火后散布开始回落的延迟，秒。
SpreadExponent锥内随机分布形状；1 为均匀，较大时更集中于中心，较小时更靠边缘。

武器实例中的 BulletsPerCartridge 控制每发弹丸数，MaxDamageRange 影响远处弹着的实际离散距离，BulletTraceSweepRadius 影响命中检测宽度；它们不改变散布角。

5 · 弹匣容量、备弹与射速

弹药数量在武器物品定义中设置，射速在开火能力中设置；它们不属于 DA_Recoil_* 的后坐力参数。

要修改的内容位置与参数含义
弹匣容量ID_Rifle 或 ID_Rifle_7 → InventoryFragment_SetStats → Lyra.ShooterGame.Weapon.MagazineSize一个弹匣最多可装多少发；两把枪需分别修改。当前均为 30。
出生时弹匣内子弹同一物品定义 → Lyra.ShooterGame.Weapon.MagazineAmmo新建武器实例时已经装入弹匣的发数。想满弹匣出生，通常将其设为与 MagazineSize 相同；当前均为 30。
初始备弹同一物品定义 → Lyra.ShooterGame.Weapon.SpareAmmo新建武器实例时弹匣外可供换弹的数量，不含弹匣内子弹；当前均为 60。
全自动射速ShooterCore/Weapons/Rifle/GA_Weapon_Fire_Rifle_Auto → Fire Delay Time Secs连续两发之间的最短间隔，单位秒；越小射速越快。当前 0.12 秒，约每秒 8.33 发、每分钟 500 发。
是否全自动同一开火能力 → Auto Rate当前为 1，对应全自动开火。
修改后：保存对应资产并重新进入 PIE。弹药初始值只在武器实例创建时写入，已经拿在手上的武器不会随资产修改而更新。ID_Rifle 与 ID_Rifle_7 的弹药数值相互独立；两把枪目前共用 GA_Weapon_Fire_Rifle_Auto，修改射速会同时影响两把枪。

6 · Debug 命令

在 PIE 控制台输入。调试倍率只在运行时生效，不会写回资产。

命令作用
Lyra.Recoil.Enable 0/1后坐力总开关；关闭后不施加后坐力弹道偏移及镜头偏移。资产散布仍可独立生效。
Lyra.Recoil.Scale <倍率>全局后坐力调试倍率，影响 Pitch/Yaw/Roll，不修改资产；默认 1。
Lyra.Recoil.Debug 0/1开关后坐力数值面板。
Lyra.Recoil.DebugDraw 0/1开关世界内后坐力轨迹、相机偏移、回正和 Roll 可视化。
Lyra.Recoil.RollShake <倍率>仅对最终 Roll 显示振幅加倍率；0 可做 Roll 关闭对照，默认 1。不改变资产或 CSV 中的原始 Roll 值。
Lyra.Recoil.RollDebug 0/1开关 Roll 实时数值与波形面板。
Lyra.Recoil.SpreadDebug 0/1开关散布实时面板，独立于其他面板。
Lyra.Recoil.Dump导出当前连发记录到 Saved/RecoilDump_*.csv；新一轮的历史会替换前一轮。
Lyra.Recoil.ReloadProfile强制从磁盘重载当前武器的后坐力资产；编辑器内直接修改资产通常会热生效。
Lyra.Recoil.Trace 0/1回正与连发问题的详细追踪日志；仅在需要定位时开启。
lyra.Weapon.DrawBulletTraceDuration <秒>绘制弹丸实际轨迹，用于观察散布。
lyra.Weapon.DrawBulletHitDuration <秒>绘制弹着点；lyra.Weapon.DrawBulletHitRadius <cm> 调整点半径。

7 · 面板读数与排错

后坐力面板

字段怎么看
ON/OFF · Scale · Profile系统开关、调试倍率、当前武器资产；切枪后确认 Profile 随之变化。
ShotIndex · Kick V/H本轮发序号及最近一发实际垂直/水平力度。
Accum Pitch/Yaw · Cam Pitch/Yaw逻辑累计偏移与镜头当前输出；插值模式下二者可暂时不同。
Mode · Stage · SubSteps · StageT单发模式、当前阶段、当帧子步数和阶段内时间。两把示例步枪应显示 Interpolated；Drop 期间主状态应为 Recovering。
State · RecoveryTimer · delay · prog主状态、距上次开火时间、停留时长和回正进度。
Pose · Seed · History当前姿态与生效倍率、随机种子、可导出的发数。
PushComp P/Y · CoverUsed P/Y · Applied · AimNow实时压枪量、回正时冻结的抵扣量、是否进入过回正的观测位，以及当前输入瞄准角。Applied 只供观察，不控制抵扣。

世界可视化与独立面板

绿线：未施加后坐力的逻辑瞄准轴。
红线：施加后坐力后的相机方向。
黄点：固定 Pattern 轨迹。
青条：回正进度。
品红弧：Roll 倾角。

RollDebug 中的 Roll 是实时横滚角，Envelope 是当前衰减比例，t/left 是已过/剩余时间，StartAmp 是本发起始振幅。SpreadDebug 中的 Model/AssetSpread 表示当前散布链路；Cone: raw → effective 是姿态原始全锥角到瞄准、移动倍率作用后锥角；Fed to cone 是弹丸采样使用的半角。

常见判读：改散布资产无效时先看 AssetSpread 是否为 on；连发散布不涨时看当前姿态的 AddPerShot 与 Max；空中不回落时看空中 RecoverRate 是否为 0。后坐力回正后仍保留偏移时，对照 CoverUsed 与本轮峰值；压过头后画面低于起枪角是当前规则。Drop 中再次开火会开始新一轮，ShotIndex 重置属于预期。

同时打开后坐力可视化与 Lyra 弹道绘制会出现两套红/黄图元：后坐力黄点展示 Pattern，Lyra 红线展示每颗弹丸的实际轨迹。
