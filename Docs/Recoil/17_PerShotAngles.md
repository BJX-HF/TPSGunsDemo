# 逐发角度配置

2026-10-11：后坐力逐发参数改为直接保存角度。本文为当前定义；此前文档中的归一化 X/Y、基础强度及固定段逐发倍率公式仅描述旧格式。

## 配置与计算

- `PatternPoints[i].X`：该发水平偏移角度（Yaw，度），右正、左负。
- `PatternPoints[i].Y`：该发新增垂直角度（Pitch，度），正数上抬、负数下移；没有原来的 1.0 上限。
- 数组内角度直接作为理论 Kick。基础水平/垂直强度和 `VerticalKickCurve` 不再重复参与数组内计算。
- 姿态、瞄准和全局强度仍作为倍率参与运行时计算。回弹、回正、累计上限等后续规则继续生效，因此理论 Kick 与最终镜头位移可能不同。
- 本次改的是逐发点的单位。回正时间、上抬/回弹曲线的 0～1 进度仍是归一化进度。

例：前两发 Pitch 分别为 1.2°、0.8°，画布中的累计 Pitch 分别为 1.2°、2.0°。

## 编辑器

左侧“逐发 Yaw° / 逐发 Pitch°”直接编辑角度；画布及“累计 Yaw° / 累计 Pitch°”编辑累计位置。固定段点可编辑，随机水平尾段虚线为只读预览。

画布显示一格对应的角度比例尺，随缩放更新。吸附步长与当前显示网格间距是两个不同的量。

移动一个累计点会改变该发与下一发的增量。角度格式允许累计 Pitch 下降，因此某一发可以产生负的垂直增量。超过 1° 的合法角度可以直接提交；原“调整基础强度以容纳被拒绝目标”按钮在角度格式中隐藏。

## 随机尾段

`PatternLength` 仍划分固定水平段和随机水平段。数组内所有发的 Pitch 都直接读取配置角度，尾段 X 保留但不参与随机水平计算。

- **尾段水平随机范围**（`HorizontalRandomRangeDegrees`）：确定性随机游走的 ±角度范围，单位为度。
- **数组外每发上抬角度**（`TailPitchDegrees`）：超过 `PatternPoints` 数组后每发的基础上抬角度。
- **数组外启用上抬倍率曲线**（`bUseTailPitchCurve`）：启用时，数组外 Pitch = `TailPitchDegrees × VerticalKickCurve(发序号)`；关闭时直接使用 `TailPitchDegrees`。

尾段参数独立于最后一个数组点。编辑最后一发、插入、删除和重排不会隐式改写数组外尾段参数。

## 旧资产兼容

新增 `LyraRecoilPatternAngles` 自定义序列化版本。旧包加载时进行一次原子转换：

```
新 X[i] = 旧 RecoilPerShot_Horizontal × 旧 X[i]
新 Y[i] = 旧 RecoilPerShot_Vertical × 旧 Y[i] × 原曲线在 i 的倍率
尾段水平范围 = 旧 RecoilPerShot_Horizontal × 旧 HorizontalRandomRange
数组外上抬角度 = 旧 RecoilPerShot_Vertical × 原数组最后一个 Y
```

空数组时旧 Y 的退化值为 1。转换时保留原曲线并启用数组外倍率曲线，使数组外任意发序号继续使用旧定义；不把有限发数采样误当作整个无限尾段。

加载转换不自动保存或标脏正式资产；编辑并保存后写入新格式版本，随后加载不会二次乘基础强度。迁移失败时保留整份旧数据和旧计算分支并输出诊断，不写入部分结果。旧基础字段保留用于兼容，在角度资产的参数界面中隐藏。

新建配置直接初始化为角度格式。复制、显式模板构造及撤销保留源单位，只有读取旧磁盘包才按版本执行迁移。

## 复制、粘贴与回归

角度剪贴板采用 `LyraRecoilClipboard/v2`，显式写入 `units=degrees`。继续读取 v1；跨单位粘贴使用载荷中的源角度转换，缺少源角度时拒绝并提示重新复制。不会把旧比例直接解释成角度。

新增 `Lyra.Recoil.Angles.*` 非视觉自动化，覆盖直接角度、正负垂直增量、倍率与尾段、旧格式转换、跨单位复制粘贴、事务/预览和五份正式旧资产当前数据的转换前后对比（100 发、3 种子）及既有 Golden 回归。既有归一化数值测试明确覆盖兼容分支；历史 Golden 不因本次实现修改而重新生成。

当前构建与测试结果记录于 `后座GUI开发/验收/20261011-逐发角度配置.md`。实际视觉效果由用户在编辑器中确认。
