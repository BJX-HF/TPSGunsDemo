连续射击时 Roll 怎么算，画面会怎样

这页按项目当前实现解释 ULyraRecoilProfile::BuildRollShakeParams、ULyraCameraRollShake::EvaluateRollShake 和 FRecoilRuntimeState::ApplyShot 的真实链路。Roll 是绕相机视线轴的倾斜角，和 Pitch/Yaw 的累计、回正互相独立。

1. 一发震动的计算链

① 开火时装配本发参数

index = max(ShotIndex, 0) rampCount = max(0, index - RampStartShot + 1) bonus = min(rampCount × AmplitudePerShot, MaxAmplitudeBonus) base = max(0, Amplitude + bonus) AmplitudeDegrees = base × SegmentScale(index) × max(0, PoseMultiplier) × max(0, GlobalScale) PeriodSeconds = Period × max(epsilon, PeriodScale(index))

C++ 字段默认值（不代表当前武器资产实值）：基础振幅 0.6°、时长 0.22 s、周期 0.055 s；从序号 4（0 起）开始每发 +0.05°，最多 +0.9°。按 0 起序号：index 0～3 仍是 0.6°；index 4（人类计数第 5 发）为 0.65°；index 21（第 22 发）达到 1.5°，之后封顶。

② 每帧解析求值

u = clamp(Elapsed / Duration, 0, 1) Envelope(u) = if DecayCurve 有键： clamp(lerp(clamp(Curve(u), 0, 1), clamp(EndAmplitudeRatio, 0, 1), u), 0, 1) else：lerp(1, clamp(EndAmplitudeRatio, 0, 1), u) phase = 2π × Elapsed / Period + PhaseOffset RollDegrees = AmplitudeDegrees × Envelope(u) × cos(phase)

Elapsed ≥ Duration 时直接返回 0，并停用本次状态。相位扰动是确定性的：DeterministicSignedRandom(HashCombine(Seed, ShotIndex)) × PhaseJitterRadians，同一种子和发序号可复现。

衰减曲线的一个细节：空曲线且 EndRatio=0 时 E=1−u；如果手工给出 Curve(u)=1−u，代码还会再向终值混合，实际 E=(1−u)²，衰减更快。
关键语义：Roll 不把上一帧的角度累加到下一帧，也不走 Pitch/Yaw 的回正状态机；它按当前时间直接求解，所以帧率只影响采样密度，不会产生积分漂移。但这不等于各帧率视觉相同：默认周期 0.055 s ≈ 18.18 Hz，在 60 fps 每周期仅约 3.3 个采样点，低帧率可能混叠，看起来像慢抖。

2. 连发时发生什么

每次 ApplyShot 成功后，都会调用 BuildRollShakeParams(ShotIndex,...)，随后 ULyraCameraRollShake::Trigger 把该发设为新的 ActiveParams、Elapsed=0，并立即采样 t=0。于是上一发尚未走完的 Roll 会被本发覆盖；高速连发时，玩家看到的是一串“重新起跳、相位略有变化、还没完全衰减就被下一发接管”的连续横滚。

第 n 发的有效振幅： Aₙ = min(A₀ + max(0, n - r + 1)·p, A₀ + bmax) · Sₙ · Pose · GlobalScale 第 n 发在其局部时间 τ 内： Rₙ(τ) = Aₙ · E(τ / D) · cos(2π τ / Tₙ + φₙ) 0 ≤ τ < D；τ ≥ D 时 Rₙ = 0

如果射速间隔 Δt 小于时长 D，下一发会在上一发结束前触发；因此可见曲线由多个局部波段拼接，而不是把角度相加。每发重启近正峰，会产生瞬时跳变；连发时间平均角度不保证为零。每发的 PhaseOffset 默认范围 ±0.35 rad，会让起始峰值和摆动时序略有变化（默认 ±0.35 rad 的 cos 仍为正，所以不会随机选择初始左右方向），避免机械重复。

5. 运行时调试入口

开发版中 Roll 面板独立于普通后坐力面板，输入以下 CVar：

Lyra.Recoil.RollGraph 1       // 新增：5秒滚动实测曲线，raw/display Roll 与开火标记
Lyra.Recoil.RollDebug 1       // 屏幕显示当前 Roll、包络、t/D、参数和 ASCII 曲线
Lyra.Recoil.RollShake 0       // 只关闭显示层 Roll，便于 A/B 对比；不改资产
Lyra.Recoil.RollShake 1       // 恢复默认显示倍率
Lyra.Recoil.DebugDraw 1       // 世界内品红圆弧表示当前横滚角
Lyra.Recoil.Dump              // 导出本轮连发 CSV 到 Saved/RecoilDump_*.csv

面板中的 Waveform t=0..D 使用与运行时相同的 EvaluateRollShake(Params, SampleTime, Roll.PhaseOffset) 采样，并用 | 标出当前时刻。RollGraph 的 Display 是提交给 recoil modifier 的 Roll 目标偏移；最终 POV 可能继续叠加其他 camera shake，也可能包含切枪时 ClearRecoilOffset 的释放过程，不能把 Display 当作最终屏幕总 Roll。当前武器这条 Roll 自身在最后一发 D 秒到点后归零。新增 RollGraph 观察连续射击的真实帧采样，RollDebug 观察本发理论波形，两者用途不同。CSV 的 RollShake 列是按姿态倍率=1、全局倍率=1、相位=0 重建的标称 t=0 值，不能还原真实连发时间曲线。

6. 调参时应该看什么

“越打越抖”

调 AmplitudePerShot 与 MaxAmplitudeBonus；RampStartShot 决定从第几发开始显著。想做分段轻重，用 SegmentScaleCurve，它是倍率，可先降后升。

“越打越急”

用 PeriodScaleCurve 让后段倍率小于 1；周期变短后，同样的 0.22 s 内会出现更多周期。注意周期和射速的关系：当 Δt 接近或小于 D，覆盖感会更强。

“每发都一样太机械”

增加 PhaseJitterRadians（默认 0.35 rad）。固定 Seed 与 ShotIndex 时，非零扰动也能复现；设为 0 只是取消相位随机，方便隔离波形和制作简单 Golden。

“结束时还歪着”

Roll 在 D 到点时无条件归零；EndAmplitudeRatio 只影响包络末段，不能把震动延伸到 D 之后。若需要更长释放，增加 Duration 或调整衰减曲线。
