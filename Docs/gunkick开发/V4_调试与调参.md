# V4 调试与调参记录（待画面验收）

时间：2026-09-23 CST。用户要求继续 V4。这里记录实现和验证，不把 V0–V4 的画面判据标记为通过。

## 工具入口

- 两把步枪继续使用各自的 `ULyraRecoilProfile` 资产：`DA_Recoil_Rifle_S` 与 `DA_Recoil_Rifle_7`。`WeaponVisual` 中的六轴脉冲、持续时间、回落、Clamp、右手与 IK 目标各自的骨空间轴，可在资产 Details 里按枪调整，无需改 C++。轴的符号及握把位置仍须在实际网格画面中校准。目前两个资产 `WeaponVisual.bEnabled` 均保持关闭。
- `Lyra.Recoil.Visual 0/1`：只关闭或开放已在资产启用的枪体视觉通道；不改变镜头和弹道。
- `Lyra.Recoil.VisualScale <非负数>`：临时视觉倍率，新开火的脉冲使用该值；正式数值应写回各枪资产。
- `Lyra.Recoil.VisualLeftIK 0/1`、`Lyra.Recoil.VisualAlignment 0/1`：分别消融左手跟随与弱镜头对齐。前者仅影响左手目标权重，后者仅移除发布姿态中的相机对齐项。
- `Lyra.Recoil.VisualDebug 0/1`：显示当前资产、发序号、ADS、镜头三轴、枪体六轴和右手/左手 IK 权重。
- `Lyra.Recoil.VisualTrace 1` 开始逐帧记录；`Lyra.Recoil.VisualTrace 0` 暂停；`Lyra.Recoil.VisualDump` 导出 `Saved/GunKickTrace_<timestamp>.csv` 并清空本轮缓存。上限 36000 帧，避免无界内存增长。现有 `Lyra.Recoil.Dump` 的八列格式不变。
- [GunKick_曲线对照.html](GunKick_曲线对照.html) 在浏览器打开，载入一个或多个新 CSV。实线镜头、虚线枪体，竖线为发序号变化；可按首帧对齐不同帧率录制。

## 建议的实机调参顺序

1. 在 PIE 中分别装备两把步枪，先以 `WeaponVisual.bEnabled=false` 录制单发、三发、持续开火的镜头基线，并记录 30/60/120 FPS 与录屏文件名。V0 的未加枪体后座视频仍是必须的对照。
2. 核对 `weapon_r`、`hand_r`、`ik_hand_r` 和步枪模型三轴及真实握把位置，再在对应 `DA_Recoil_*` 的 `WeaponVisual` 中设定两套骨空间轴。不要只用默认向量判断方向。先开低倍率单发，确认后退、抬枪、转向方向。
3. 调 Pitch/Back，再调 Yaw/Roll/Up/Side；随后调每轴 Clamp、攻击/峰值/回落时长。比较枪体峰值与镜头 Lift 的时间、连发时左右肘可达范围、枪体回基姿的速度。
4. 启用目标式右手 IK 和左手跟随，测左手与前握把的误差；执行 `VisualLeftIK 0/1` 对照。检验 ADS、移动、蹲姿、重装、切枪、死亡及蒙太奇抑制曲线。
5. 使用 `VisualTrace` 每种情形录一份 CSV，加载曲线页叠图；结合屏幕录制确认相位和穿模。关闭 `VisualTrace` 后再 Dump，防止导出时采样继续增长。
