# Gun Kick V2 进度与验收

时间：2026-09-23 CST。用户本轮明确要求继续 V2；原开发方案要求 V0→V1→V2 逐阶段验收，目前 V0 的录屏及骨轴核对、V1 的两枪实机验收仍未完成。本轮只记录 V2 实现进度，不宣称任何阶段验收通过，也不进入 V3。

## 已实现

- `FWeaponVisualRecoilSettings` 新增 Yaw、Roll、Up、Side 的本发映射、六轴独立上限、额外 ADS 视觉倍率、弱镜头 Pitch/Yaw 对齐系数及独立对齐上限。每轴另有手骨 Bone Space 校准方向；两枪视觉开关保持默认关闭。
- `FWeaponVisualRecoilState` 使用同次成功开火记录中的实际 `HorizontalKick` 确定 Yaw 和 Side 符号，Roll 随 Yaw 映射；没有另抽水平随机方向。机械六轴继续用 1/120 秒定步推进，短峰值停留后回位，连发逐轴 Clamp。对齐项只在输出 Pose 时读取既有 `CameraOffsetPitch/Yaw` 并钳制，不反馈到机械状态或镜头、弹道。
- 本发实际 Vertical/Horizontal Kick 已经包含游戏姿态及全局倍率；代码只给位移基量再乘对应倍率，避免对角度 Kick 重复乘。视觉 ADS 倍率按当前 `AimingAlpha` 混合，由每枪独立调节。
- `ULyraWeaponAnimLayerInstance` 将六轴语义 Pose 按 Profile 的每轴校准向量写入既有 `GunKickHandTranslation` / `GunKickHandRotation`，沿用 V1 已接入的 `hand_r` 动画图节点。
- 新增 `Lyra.Recoil.WeaponVisualV2.SixAxisMapping` 和 `AlignmentAndADS` 自动化测试，覆盖左右方向、零水平 Kick、六轴上限、连发约束、ADS 视觉强度、弱对齐限幅及对齐不回灌。
